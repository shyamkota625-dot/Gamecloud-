GameCloud website
==================
Open index.html in a browser.

Included:
- Clean/minimal GameCloud design
- Home and Discover sections
- Searchable game catalog: Grand Theft Auto V, Red Dead Redemption, Red Dead Redemption 2, Human Fall Flat, Cricket 24
- Save-to-library using browser localStorage
- GameCloud Pass pricing:
  1 Month — ₹300
  3 Months — ₹750
  1 Year — ₹2,500
- Responsive mobile layout

Note: the Play buttons are demo interactions. Real PC/cloud games require a game delivery/streaming system and the appropriate game licenses. Payment is also a placeholder until a payment provider/backend is connected.

Important: these titles are displayed as catalog entries. Actual gameplay requires legitimate ownership/licensing and a supported PC/cloud-game delivery system; this site does not include pirated game files.
